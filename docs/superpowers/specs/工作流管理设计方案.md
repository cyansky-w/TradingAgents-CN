### 3.2 DAGResolver -- 拓扑排序与校验

```python
class DAGResolver:
    """解析 nodes+edges，校验合法性，输出拓扑执行层级。"""

    @staticmethod
    def validate(nodes: list, edges: list) -> list[str]:
        """校验 DAG 合法性，返回错误列表。
        - 检测环
        - 检测孤立节点（无入边且非 start 节点）
        - 检测节点引用的 agent_id / workflow_id 是否有效
        """

    @staticmethod
    def topological_sort(nodes: list, edges: list) -> list[list[str]]:
        """返回分层执行计划。
        [
            ["start"],                              # 第 0 层
            ["market_analyzer"],                    # 第 1 层
            ["stock_analyzer", "deep_analysis"],    # 第 2 层（并行）
            ["summary"],                            # 第 3 层
            ["end"],                                # 第 4 层
        ]
        """
```

### 3.3 ExecutionContext -- 运行时变量池

```python
class ExecutionContext:
    """维护工作流运行时的变量和节点输出。"""

    def __init__(self, workflow_input: dict):
        self.variables = {"input": workflow_input}
        self.node_outputs: dict[str, Any] = {}
        self.token_usage: dict[str, dict] = {}

    def resolve_mapping(self, mapping: dict) -> dict:
        """解析 input_mapping 中的模板变量。
        {{input.date}}        -> context.variables["input"]["date"]
        {{market_analyzer.output}} -> context.node_outputs["market_analyzer"]["output"]
        {{item.symbol}}       -> 循环中的当前元素
        """

    def render_template(self, template: str) -> str:
        """渲染 message_template 等模板字符串，替换 {{...}} 为实际值。
        {{input.date}}    -> "2026-05-22"
        {{input.symbols}} -> "['000001', '600519']"
        """

    def set_node_output(self, node_id: str, output: Any):
        self.node_outputs[node_id] = output

    def get_final_output(self, output_template: str) -> Any:
        """根据 output_template 提取最终输出。"""
```

### 3.4 GraphBuilder -- 动态构建 StateGraph

```python
from typing import TypedDict, Annotated
from langgraph.graph import StateGraph, START, END

class WorkflowState(TypedDict):
    context: dict              # ExecutionContext 的序列化形式
    node_outputs: dict         # {node_id: output}
    current_node: str
    errors: Annotated[list, operator.add]


class GraphBuilder:
    """从 MongoDB 工作流文档动态构建 LangGraph StateGraph。"""

    def __init__(self, workflow_doc: dict, run_id: str, workflow_message: str):
        self.workflow = workflow_doc
        self.run_id = run_id
        self.workflow_message = workflow_message  # 渲染后的工作流用户消息
        self.ctx = ExecutionContext(workflow_doc.get("input", {}))

    async def build(self) -> CompiledGraph:
        graph = StateGraph(WorkflowState)

        for node in self.workflow["nodes"]:
            executor = self._create_node_executor(node)
            graph.add_node(node["id"], executor)

        for edge in self.workflow["edges"]:
            graph.add_edge(edge["source"], edge["target"])

        # START -> 第一个节点（入度为 0 的 io input 节点）
        entry = self._find_entry_node()
        graph.add_edge(START, entry)

        # 最后一个节点 -> END
        exit_node = self._find_exit_node()
        graph.add_edge(exit_node, END)

        return graph.compile()

    def _create_node_executor(self, node: dict) -> Callable:
        """根据节点类型创建执行函数。"""
        node_type = node["type"]

        if node_type == "agent":
            return AgentNodeExecutor(node, self.ctx, self.run_id, self.workflow_message)
        elif node_type == "subflow":
            return SubflowNodeExecutor(node, self.ctx, self.run_id)
        elif node_type == "io":
            return IONodeExecutor(node, self.ctx)
```

### 3.5 消息流转模型

工作流的核心消息模型：**一条用户消息 → 多个 Agent 协作处理**。

```
工作流 message_template（必填）:
"请对 {{date}} 的市场进行全方位分析，重点关注以下标的：{{symbols}}"
                    │
                    │  渲染变量后得到 user_message
                    ▼
    ┌───────────────┼───────────────┐
    ▼               ▼               ▼
市场分析师        个股分析师       风险分析师
(system_prompt    (system_prompt    (system_prompt
 定义了角色)      定义了角色)      定义了角色)
    │               │               │
    │ 同一条 user_message，各自从自己的角色角度处理
    ▼               ▼               ▼
 输出市场分析     输出个股分析     输出风险评估
                    │
                    ▼
              总结 Agent
              (收到上游所有输出
               作为上下文)
```

**消息来源优先级**：

| 调用场景 | HumanMessage 来源 |
|----------|-------------------|
| 工作流执行 | workflow.message_template 渲染后的文本 |
| Agent 单独 test-run | agent.message_template 渲染后的文本 |
| Agent 作为工具被调用 | 调用方传入的参数 |

**Agent 节点的输入处理**：

```python
# Agent 节点 config 中的 input_mapping 用于提示词模板变量渲染
# 而不是构造 HumanMessage
"config": {
    "agent_id": "ObjectId_str",
    "input_mapping": {             # -> build_agent(variables) -> render_prompt
        "date": "{{input.date}}",
        "ticker": "{{input.symbols}}",
    },
    "loop_over": None,
    "parallel": False,
    "max_concurrency": 1,
}

# 执行时：
# 1. input_mapping 解析变量 -> build_agent(variables) 渲染提示词模板
# 2. workflow.message_template 渲染变量 -> 作为 HumanMessage
# 3. 两者解耦：提示词变量和用户消息各自独立
```

**上游输出作为上下文传递**：

后层 Agent（如总结 Agent）需要上游输出时，通过 `input_mapping` 注入到提示词变量中，
HumanMessage 仍然是工作流的同一用户消息。Agent 的 system_prompt 中应包含"综合以下分析结果..."的指令。

### 3.6 节点执行器

```python
class AgentNodeExecutor:
    """执行单个 Agent 节点，内部复用 create_react_agent。"""

    def __init__(self, node: dict, ctx: ExecutionContext, run_id: str, workflow_message: str):
        self.node = node
        self.ctx = ctx
        self.run_id = run_id
        self.workflow_message = workflow_message  # 工作流渲染后的用户消息

    async def __call__(self, state: WorkflowState) -> dict:
        config = self.node["config"]
        agent_id = config["agent_id"]

        # 1. 解析提示词变量（input_mapping -> render_prompt）
        variables = self.ctx.resolve_mapping(config.get("input_mapping", {}))

        # 2. 处理 loop_over（循环执行）
        if config.get("loop_over"):
            loop_source = self.ctx.resolve_value(config["loop_over"])
            results = await self._execute_loop(agent_id, variables, loop_source, config)
            self.ctx.set_node_output(self.node["id"], {"output": results})
        else:
            # 3. 构建 Agent：build_agent 渲染提示词模板 + 解析工具 + 创建 LLM
            spec = await agent_service.build_agent(agent_id, variables)

            # 4. 构造消息：system_prompt + workflow 的用户消息
            messages = [
                SystemMessage(content=spec.system_prompt),
                HumanMessage(content=self.workflow_message),
            ]

            # 5. 执行：有工具用 create_react_agent，无工具直接调用 LLM
            if spec.tools:
                react_agent = create_react_agent(spec.llm, spec.tools)
                result = await react_agent.ainvoke(
                    {"messages": messages},
                    config={"recursion_limit": spec.parameters.max_tool_calls},
                )
                output = self._extract_output(result)  # 取最后一条非 tool_calls 的 AI 消息
            else:
                result = await spec.llm.ainvoke(messages)
                output = result.content

            self.ctx.set_node_output(self.node["id"], {"output": output})

        # 6. 更新运行记录
        await run_recorder.update_node(self.run_id, self.node["id"], status="completed", ...)

        return {
            "node_outputs": {self.node["id"]: self.ctx.node_outputs[self.node["id"]]},
            "current_node": self.node["id"],
            "errors": [],
        }

    def _extract_output(self, result: dict) -> str:
        """从 create_react_agent 结果中提取最后一条 AI 回复文本。"""
        from langchain_core.messages import AIMessage
        ai_msgs = [
            m for m in result.get("messages", [])
            if isinstance(m, AIMessage) and not getattr(m, "tool_calls", None)
        ]
        return ai_msgs[-1].content if ai_msgs else ""

    async def _execute_loop(self, agent_id, variables, items, config) -> list:
        """并行或串行执行循环体，每个 item 使用同一个 workflow_message。"""
        parallel = config.get("parallel", False)
        max_concurrency = config.get("max_concurrency", 3)

        async def run_single(item):
            loop_vars = {**variables, "item": item}
            spec = await agent_service.build_agent(agent_id, loop_vars)
            messages = [
                SystemMessage(content=spec.system_prompt),
                HumanMessage(content=self.workflow_message),
            ]
            if spec.tools:
                react_agent = create_react_agent(spec.llm, spec.tools)
                result = await react_agent.ainvoke(
                    {"messages": messages},
                    config={"recursion_limit": spec.parameters.max_tool_calls},
                )
                return self._extract_output(result)
            else:
                result = await spec.llm.ainvoke(messages)
                return result.content

        if parallel:
            semaphore = asyncio.Semaphore(max_concurrency)
            async def run_with_semaphore(item):
                async with semaphore:
                    return await run_single(item)
            tasks = [run_with_semaphore(item) for item in items]
            return await asyncio.gather(*tasks)
        else:
            return [await run_single(item) for item in items]


class SubflowNodeExecutor:
    """嵌套子工作流节点，递归调用 WorkflowEngine。"""

    async def __call__(self, state: WorkflowState) -> dict:
        config = self.node["config"]
        variables = self.ctx.resolve_mapping(config.get("input_mapping", {}))

        # 递归调用引擎
        result = await workflow_engine.run(
            workflow_id=config["workflow_id"],
            input_data=variables,
            parent_run_id=self.run_id,
        )
        self.ctx.set_node_output(self.node["id"], result)
        return {...}


class IONodeExecutor:
    """输入/输出节点，负责变量映射和透传。"""

    async def __call__(self, state: WorkflowState) -> dict:
        config = self.node["config"]
        if config["io_direction"] == "input":
            # 将 workflow input 写入上下文
            self.ctx.set_node_output(self.node["id"], {"output": self.ctx.variables["input"]})
        else:
            # 根据 output_template 提取最终输出
            output = self.ctx.get_final_output(
                self.ctx.variables.get("output_template", "")
            )
            self.ctx.set_node_output(self.node["id"], {"output": output})
        return {...}
```

### 3.6 WorkflowEngine -- 执行入口

```python
class WorkflowEngine:
    """工作流执行引擎。"""

    async def run(
        self,
        workflow_id: str,
        input_data: dict,
        trigger_type: str = "manual",
        parent_run_id: str | None = None,
    ) -> dict:
        # 1. 加载工作流定义
        workflow = await workflow_service.get_workflow(workflow_id)

        # 2. 渲染工作流用户消息（message_template + input_variables）
        ctx = ExecutionContext(input_data)
        workflow_message = ctx.render_template(workflow["message_template"])

        # 3. 创建运行记录
        run_doc = await run_recorder.create_run(workflow_id, input_data, trigger_type)

        # 4. 动态构建 StateGraph（传入渲染后的消息）
        builder = GraphBuilder({**workflow, "input": input_data}, str(run_doc["_id"]), workflow_message)
        graph = await builder.build()

        # 5. 执行（带超时）
        timeout = workflow.get("settings", {}).get("timeout", 3600)
        try:
            result = await asyncio.wait_for(
                graph.ainvoke({"context": {}, "node_outputs": {}, "current_node": "", "errors": []}),
                timeout=timeout,
            )
            await run_recorder.complete_run(str(run_doc["_id"]), result)
        except asyncio.TimeoutError:
            await run_recorder.fail_run(str(run_doc["_id"]), "执行超时")
        except Exception as e:
            await run_recorder.fail_run(str(run_doc["_id"]), str(e))

        return run_recorder.get_run_output(str(run_doc["_id"]))
```

### 3.7 SSE 实时状态推送

```python
async def workflow_run_events(run_id: str):
    """SSE 事件流，推送节点执行状态。"""
    last_status = None
    while True:
        run = await run_recorder.get_run(run_id)
        if run["status"] != last_status:
            yield f"event: status\ndata: {json.dumps({...})}\n\n"
            last_status = run["status"]
        if run["status"] in ("completed", "failed", "cancelled"):
            break
        await asyncio.sleep(1)
```

### 5.5 校验功能（流通性 + 可执行性）

工作流必须通过校验才能保存和运行。校验分两层：

**前端校验（实时）** -- `useWorkflowValidation.ts`:

```
校验规则:

1. 结构完整性（流通性）:
   - 必须有且仅有一个 input IO 节点和一个 output IO 节点
   - 所有节点必须可达（从 input 到 output 存在路径）
   - 不能有环（DAG 约束）
   - 节点不能有悬空连线（每条边的 source/target 必须存在）

2. 配置完整性:
   - Agent 节点必须绑定有效 agent_id
   - Subflow 节点必须绑定有效 workflow_id
   - Subflow 不能引用自身（防止无限递归）
   - input_mapping 引用的变量源必须存在（上游节点输出或 input 变量）

3. 可执行性:
   - 引用的 Agent 必须处于启用状态
   - 引用的 Agent 绑定的提示词必须启用
   - 引用的 Agent 绑定的工具必须启用
   - 引用的 Subflow 工作流本身也必须通过校验（递归校验）
   - 循环节点的 loop_over 指向的源必须返回数组类型

实时提示:
- 画布上有问题的节点/边标红
- 工具栏校验按钮显示状态: ✓ 通过 / ❌ N个问题
- 底部状态栏: "3 个问题: 1 个孤立节点, 1 个未配置 Agent, 1 个无效映射"
```

**后端校验（保存/运行时）** -- `POST /api/workflows/{id}/validate`:
