# 实盘交易记录系统 — 设计方案

**日期**：2026-05-18
**版本**：v1.0
**状态**：已确认

---

## 一、概述

在现有"模拟交易"之外，新增一套独立的**真实交易记录系统**。不与券商对接，通过手动录入方式记录用户的真实交易，根据交易记录和实时行情动态计算持仓信息，并提供仪表盘看板用于交易复盘。

## 二、数据库设计

### 新增集合：`real_trades`

```json
{
  "_id": ObjectId,
  "user_id": "string",

  "code": "600519",           // 股票代码
  "market": "CN",             // CN / HK / US
  "currency": "CNY",          // CNY / HKD / USD
  "name": "贵州茅台",           // 股票名称（录入时快照）

  "side": "buy",              // buy / sell
  "price": 1650.00,           // 成交单价
  "quantity": 100,            // 数量（股）
  "amount": 165000.00,        // 成交金额 = price * quantity
  "commission": 15.00,        // 手续费（选填）

  "trade_date": "2026-05-15T10:30:00",  // 实际交易时间

  "reason": "突破前高，量能配合",  // 交易原因（必填）
  "tags": ["白酒", "突破"],       // 标签（选填）
  "notes": "止损设在1550",        // 备注（选填）

  "created_at": "...",
  "updated_at": "..."
}
```

### 索引

| 索引 | 用途 |
|------|------|
| `{user_id: 1, trade_date: -1}` | 按时间倒序查询 |
| `{user_id: 1, code: 1}` | 按标的查询 |
| `{user_id: 1, side: 1}` | 按买卖方向筛选 |
| `{user_id: 1, tags: 1}` | 按标签筛选 |

### 设计原则

- **持仓不存库** — 通过聚合交易记录 + 实时行情动态计算
- **买入加权成本** — 成本均价仅按买入记录加权平均
- **卖出盈亏** — 每笔卖出时直接从 (卖出价 - 成本均价) * 数量 体现

## 三、持仓计算逻辑

```
对每个标的:
  total_buy_qty   = Σ(所有买入数量)
  total_buy_cost  = Σ(所有买入数量 × 买入单价)
  total_sell_qty  = Σ(所有卖出数量)

  剩余数量   = total_buy_qty - total_sell_qty
  成本均价   = total_buy_cost / total_buy_qty   (仅按买入加权，>0时)
  成本总价   = 成本均价 × 剩余数量
  实时单价   = 从 market_quotes / ForeignStockService 获取
  实时总价   = 实时单价 × 剩余数量
  浮动盈亏   = (实时单价 - 成本均价) × 剩余数量
  盈亏比例   = (实时单价 / 成本均价 - 1) × 100%
  仓位占比   = 该标的总市值 / 所有持仓总市值 × 100%
```

剩余数量为 0 的标的从持仓列表中移除。

## 四、API 设计

新建 `app/routers/real_trades.py`，路由前缀 `/api/real-trades`：

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/positions` | 获取持仓列表（实时计算 + 行情） |
| `GET` | `/records` | 分页查询交易记录，支持筛选（code / side / tags / pnl / start / end / page / page_size） |
| `POST` | `/record` | 新增一条交易记录 |
| `PUT` | `/record/{id}` | 修改交易记录 |
| `DELETE` | `/record/{id}` | 删除交易记录 |
| `GET` | `/dashboard` | 仪表盘汇总数据 |

### `GET /records` 筛选参数

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `code` | str | - | 标的代码模糊匹配 |
| `side` | str | - | buy / sell |
| `tags` | str | - | 逗号分隔，多标签交集匹配 |
| `pnl` | str | - | profit / loss，按卖出盈亏筛选 |
| `start` | str | - | 起始日期 |
| `end` | str | - | 结束日期 |
| `page` | int | 1 | 页码 |
| `page_size` | int | 20 | 每页条数 |
| `sort` | str | desc | asc / desc，按 trade_date |

### `GET /dashboard` 返回结构

```json
{
  "total_pnl": 12500.00,
  "realized_pnl": 8000.00,
  "unrealized_pnl": 4500.00,
  "win_rate": 0.65,
  "profit_loss_ratio": 2.3,
  "holding_count": 5,
  "pnl_curve": [
    {"date": "2026-01-15", "cumulative_pnl": 1000.00},
    ...
  ],
  "sector_distribution": [
    {"code": "600519", "name": "贵州茅台", "market_value": 165000.00, "percentage": 35.0},
    ...
  ]
}
```
